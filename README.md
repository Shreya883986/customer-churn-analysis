# Customer Churn Analysis & Prediction

## Project Overview
This project analyzes customer churn behavior using Python, Machine Learning, and Power BI.

## Tools Used
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Scikit-learn
- Power BI

## Machine Learning
- Logistic Regression

## Key Insights
- Monthly contracts showed highest churn
- Support calls strongly influenced churn
- Payment delays increased churn probability

## Dashboard Features
- Interactive slicers
- KPI cards
- Churn analysis visualizations
